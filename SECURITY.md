# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of OpencodeSilver very seriously. If you discover a security vulnerability, please report it privately:

- **Do NOT open a public GitHub issue** for sensitive security vulnerabilities.
- Please email the maintainer directly at security@opencodesilver.dev or submit a private security advisory through GitHub Security Advisories.
- Include detailed steps to reproduce the issue, proof-of-concept code or payloads, and the affected environments.

---

## Responsible Disclosure & Response

- We will acknowledge receipt of your vulnerability report within 48 hours.
- A fix will be developed and released promptly after verification.
- You will be credited in the release notes unless you prefer to remain anonymous.
