## Overview

**`@opencodesilver/vscode`** embeds the full power of the OpencodeSilver workspace right inside your primary editor. Work directly beside your code with zero context switching, execute multi-model comparisons in parallel, review staged edits in native diff views, and dispatch background tasks while continuing to write code.

---

## Key Features

- **In-Editor Chat Sidebar:** Responsive chat panel that adapts automatically to narrow and wide editor views.
- **Multi-Model Parallel Inference:** Run the same prompt across different frontier models simultaneously, compare responses side by side, and fuse the best code into your active file.
- **Contextual Right-Click Actions:** Highlight any code block to instantly add it to context, attach anchored inline comments, ask for explanations, or apply in-place optimizations.
- **Deep Editor Linking:** File paths and line numbers generated by agent tools open directly in your editor with precise cursor placements.
- **Source Control Integration:** Generate precise, conventional Git commit messages based on staged changes with one click.
- **Full Theme Adaptation:** Automatically harmonizes with your active VS Code light, dark, and high-contrast color themes.

## Extension Commands

Access these commands from the VS Code Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):

| Command | Identifier | Description |
| :--- | :--- | :--- |
| **Focus Chat** | `OpencodeSilver: Focus Chat` | Open and focus the primary chat sidebar |
| **New Session** | `OpencodeSilver: New Session` | Start a fresh conversational agent session |
| **Run on Several Models** | `OpencodeSilver: Run on Several Models` | Compare multiple models side-by-side |
| **Open Session in Editor** | `OpencodeSilver: Open Session in Editor` | Move chat into an editor tab alongside code files |
| **Generate Commit Message** | `OpencodeSilver: Generate Commit Message` | Fill Source Control commit box from staged changes |
| **Restart Connection** | `OpencodeSilver: Restart API Connection` | Reconnect or restart the local OpenCode process |

---

## Right-Click Editor Actions

Select any code block in your editor, right-click, and navigate to the **OpencodeSilver** menu:

- **Add to Context:** Appends the code block and its file location directly to your prompt input.
- **Add Comment:** Opens an anchored inline discussion thread attached to those specific lines.
- **Explain Code:** Requests a line-by-line architectural explanation from the active agent.
- **Improve Code:** Guides the agent to refactor, optimize, or fix bugs in the highlighted block.

---

## Configuration Settings

Configure these in VS Code Settings (`Ctrl+,` / `Cmd+,`) under **Extensions → OpencodeSilver**:

| Setting | Default | Description |
| :--- | :--- | :--- |
| `opencodesilver.apiUrl` | _(auto)_ | URL of an external OpenCode API server (leave blank to launch local engine) |
| `opencodesilver.opencodeBinary` | _(auto)_ | Explicit absolute path to the `opencode` CLI binary |

## Building and Local Packaging

```bash
# Start development watcher and open Extension Development Host
bun run vscode:dev

# Build extension package (.vsix)
bun run --cwd packages/vscode package

# Install the generated package locally
code --install-extension packages/vscode/opencodesilver-*.vsix
```
