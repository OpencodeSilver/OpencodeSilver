# Changelog

All notable changes to the OpencodeSilver VS Code extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-10-18

### Added
- **In-Editor Chat Panel:** Responsive sidebar that seamlessly docks alongside active code files with zero context switching.
- **Multi-Model Parallel Inference:** Run prompts across multiple frontier models simultaneously and compare or fuse generated code directly in the editor.
- **Right-Click Context Actions:** Add code to context, attach anchored inline comments, request explanations, or optimize code in-place.
- **Direct Editor Navigation:** File links and diff results open with precise line highlighting and focused diff views.
- **Git Commit Generator:** Generate conventional commit messages from staged changes with one click.
- **Theme Synchronization:** Automatic color palette adaptation for VS Code light, dark, and high-contrast themes.
- **Bilingual RTL Support:** Native right-to-left layout alignment for Arabic chat and diff views inside the editor.
