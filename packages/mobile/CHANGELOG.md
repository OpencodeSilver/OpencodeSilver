# Changelog

All notable changes to OpencodeSilver Mobile will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-10-18

### Added
- **Native Capacitor Runtime:** High-performance mobile shell for iOS and Android.
- **Instance Management:** Connect and switch seamlessly between remote OpencodeSilver servers with secure client token storage.
- **Adaptive Tablet & Foldable Layout:** Live responsive layout class expanding into a persistent navigation drawer on tablets and foldables.
- **Mobile Terminal Access:** Remote WebSocket PTY terminal interface with touch scrolling and gesture-based text selection.
- **Native Sharing Integration:** System share sheet support for exporting images, diffs, and project artifacts.
