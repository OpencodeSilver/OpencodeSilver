# Changelog

All notable changes to OpencodeSilver Web & PWA will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-10-18

### Added
- **Browser-Based Workspace:** Full OpenCode agent workflows accessible via any modern desktop or mobile browser.
- **Mobile PWA Support:** Touch-optimized layout, mobile keyboard safety, and installable home screen PWA support.
- **Private Cloudflare Tunnels:** Quick, Managed-Remote, and Managed-Local encrypted tunneling with instant QR code onboarding.
- **Cross-Tab Real-Time Sync:** Synchronized chat sessions, active diff views, and execution progress across browser tabs.
- **Background Push Notifications:** Alerts when background agent tasks, reasoning loops, or model runs complete.
- **Headless Server & CLI:** Robust `opencodesilver` CLI supporting background daemon modes, LAN bindings, and systemd services.
