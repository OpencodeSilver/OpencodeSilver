# Environment Variables

OpencodeSilver reads these environment variables at startup. For startup services, `opencodesilver startup enable` snapshots the current environment by default, so rerun it after changing variables you want the service to use.

## OpencodeSilver server

### `OPENCODESILVER_HOST`

Bind address for the OpencodeSilver web server. Use `0.0.0.0` to allow access from other machines.

### `OPENCODESILVER_UI_PASSWORD`

Password for the browser UI. Use this when binding outside localhost, using tunnels, or running behind a reverse proxy.

### `OPENCODESILVER_API_ONLY`

Starts OpencodeSilver in headless mode when set to `true` or `1`. API routes stay available for desktop and mobile clients, but the browser UI is not served.

### `OPENCODESILVER_FRAME_ANCESTORS`

Origins allowed to show OpencodeSilver inside a frame on their own page, separated by spaces, for example `https://dash.example.com`. `*` allows any site. By default only OpencodeSilver itself and its desktop and mobile apps may frame it, which keeps other sites from overlaying its buttons.

### `OPENCODESILVER_DATA_DIR`

Overrides the OpencodeSilver data directory. The default is `~/.config/opencodesilver`.

Everything OpencodeSilver stores lives under this directory: settings, auth, project configs, themes, plans, and speech models. An instance that used a custom directory before version 1.23 gets its `projects`, `themes`, and `speech-models` folders copied from `~/.config/opencodesilver` on the first start; the originals stay in place and nothing is merged.

### `OPENCODESILVER_CHATS_DIR`

Moves the managed chat directories that OpencodeSilver creates for chats without a project. The default is `~/.config/opencodesilver/chats`. Set it to a directory the OpenCode server can read when OpencodeSilver and OpenCode run as different users. Existing chats are not moved.

### `OPENCODESILVER_COMPRESS_API`

Controls API response compression. Use `true` or `1` to force it on, `false` or `0` to force it off.

### `OPENCODESILVER_SKIP_API_COMPRESSION`

Disables API response compression when set to `true` or `1`. This takes precedence over `OPENCODESILVER_COMPRESS_API`.

### `OPENCODESILVER_VERBOSE_REQUEST_LOGS`

Enables verbose HTTP request logs when set to `true` or `1`.

### `OPENCODESILVER_UPDATE_API_URL`

Overrides the update-check API endpoint. Most users should leave this unset.

### `OPENCODESILVER_PACKAGE_MANAGER`

Forces the package manager used by update operations when auto-detection is wrong.

## OpenCode server

### `OPENCODE_HOST`

Connects OpencodeSilver to an existing OpenCode server. The value must be an `http` or `https` origin with an explicit port and no path, query, or hash. `OPENCODE_HOST` takes precedence over `OPENCODE_PORT`.

### `OPENCODE_PORT`

Sets the OpenCode server port. With managed OpenCode this requests the managed port; with `OPENCODE_SKIP_START=true` it connects to an external server on that port.

### `OPENCODE_SKIP_START`

Prevents OpencodeSilver from starting its own OpenCode server when set to `true`.

### `OPENCODESILVER_OPENCODE_HOSTNAME`

Bind hostname for the OpenCode server managed by OpencodeSilver. The default is `127.0.0.1`.

### `OPENCODE_BINARY`

Path to the `opencode` executable OpencodeSilver should run.

### `OPENCODE_CONFIG`

Path to a specific OpenCode config file.

### `OPENCODE_CONFIG_DIR`

Path to a specific OpenCode config directory for agents, skills, snippets, and config discovery.

### `OPENCODE_DATA_DIR`

Custom data directory for the managed OpenCode server.

### `OPENCODE_WSL_DISTRO`

Selects the WSL distro used for OpenCode integration on Windows.

### `OPENCODESILVER_OPENCODE_WSL_DISTRO`

OpencodeSilver-specific alias for selecting the WSL distro. `OPENCODE_WSL_DISTRO` takes precedence when both are set.

### `OPENCODE_JWT_SECRET`

Secret used to sign UI authentication tokens. Use a long random value for persistent service deployments.

## Terminal and Git

### `OPENCODESILVER_TERMINAL_SHELL`

Shell executable used for OpencodeSilver terminal sessions.

### `OPENCODESILVER_GIT_BINARY`

Git executable used by OpencodeSilver Git features.

### `GIT_BINARY`

Alternative Git executable override. Prefer `OPENCODESILVER_GIT_BINARY` for OpencodeSilver-specific configuration.

### `OPENCODESILVER_GIT_READ_CACHE_TTL_MS`

Time-to-live, in milliseconds, for cached Git-backed file reads. Set `0` to disable this cache while debugging.

## Voice and tunnels

### `OPENAI_API_KEY`

API key OpencodeSilver voice features use when they call OpenAI itself. It is never sent to a custom OpenAI-compatible server: give that server its own key in Settings.

### `OPENCODESILVER_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Allows remote OpenAI-compatible base URLs for voice features when set to `true` or `1`.

### `NGROK_AUTHTOKEN`

ngrok auth token used by OpencodeSilver tunnel commands. You can also configure ngrok with `ngrok config add-authtoken <token>`.

## Runtime helpers

### `BUN_BINARY`

Bun executable OpencodeSilver should use when spawning daemon processes.

### `BUN_INSTALL`

Bun installation root. OpencodeSilver uses it to find `bin/bun` for daemon startup and updates.

### `VITE_OPENCODE_URL`

Build-time API base URL for the Vite-built web app. Most users should not set it for normal CLI or desktop usage.
