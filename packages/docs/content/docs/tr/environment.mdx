# Environment Değişkenleri

OpencodeSilver bu environment değişkenlerini başlangıçta okur. Başlangıç servisleri için `opencodesilver startup enable` varsayılan olarak mevcut environment'ı anlık görüntü olarak kaydeder. Servisin kullanmasını istediğiniz değişkenleri değiştirdikten sonra bunu yeniden çalıştırın.

## OpencodeSilver sunucusu

### `OPENCODESILVER_HOST`

OpencodeSilver web sunucusu için bind adresi. Diğer makinelerden erişime izin vermek için `0.0.0.0` kullanın.

### `OPENCODESILVER_UI_PASSWORD`

Tarayıcı arayüzü için parola. Bunu localhost dışına bind ederken, tünel kullanırken ya da reverse proxy arkasında çalıştırırken kullanın.

### `OPENCODESILVER_API_ONLY`

`true` ya da `1` olarak ayarlandığında OpencodeSilver'ı headless modda başlatır. API rotaları masaüstü ve mobil istemciler için açık kalır, ama tarayıcı arayüzü sunulmaz.

### `OPENCODESILVER_FRAME_ANCESTORS`

OpencodeSilver'ı kendi sayfalarındaki bir çerçevede gösterebilecek origin'ler, boşlukla ayrılmış, örneğin `https://dash.example.com`. `*` her siteye izin verir. Varsayılan olarak yalnızca OpencodeSilver'ın kendisi ve masaüstü ile mobil uygulamaları onu gömebilir; böylece başka siteler düğmelerinin üstüne bir şey yerleştiremez.

### `OPENCODESILVER_DATA_DIR`

OpencodeSilver veri dizinini geçersiz kılar. Varsayılan `~/.config/opencodesilver`.

### `OPENCODESILVER_CHATS_DIR`

OpencodeSilver'ın projesiz sohbetler için oluşturduğu yönetilen sohbet dizinlerinin yerini değiştirir. Varsayılan `~/.config/opencodesilver/chats`. OpencodeSilver ve OpenCode farklı kullanıcılarla çalışıyorsa OpenCode sunucusunun okuyabileceği bir dizin belirtin. Mevcut sohbetler taşınmaz.

### `OPENCODESILVER_COMPRESS_API`

API yanıt sıkıştırmasını kontrol eder. `true` ya da `1` ile zorla açın, `false` ya da `0` ile zorla kapatın.

### `OPENCODESILVER_SKIP_API_COMPRESSION`

`true` ya da `1` olarak ayarlandığında API yanıt sıkıştırmasını kapatır. Bu ayar `OPENCODESILVER_COMPRESS_API`'ye göre önceliklidir.

### `OPENCODESILVER_VERBOSE_REQUEST_LOGS`

`true` ya da `1` olarak ayarlandığında ayrıntılı HTTP istek günlüklerini açar.

### `OPENCODESILVER_UPDATE_API_URL`

Güncelleme kontrolü API uç noktasını geçersiz kılar. Çoğu kullanıcı bunu boş bırakmalıdır.

### `OPENCODESILVER_PACKAGE_MANAGER`

Otomatik algılama yanlışsa, güncelleme işlemlerinin kullandığı package manager'ı zorlar.

## OpenCode sunucusu

### `OPENCODE_HOST`

OpencodeSilver'ı mevcut bir OpenCode sunucusuna bağlar. Değer, açık bir port içeren ve path, query ya da hash içermeyen bir `http` ya da `https` origin'i olmalıdır. `OPENCODE_HOST`, `OPENCODE_PORT`'a göre önceliklidir.

### `OPENCODE_PORT`

OpenCode sunucu portunu ayarlar. Yönetilen OpenCode ile bu, yönetilen portu ister. `OPENCODE_SKIP_START=true` ile harici bir sunucuya o port üzerinden bağlanır.

### `OPENCODE_SKIP_START`

`true` olarak ayarlandığında OpencodeSilver'ın kendi OpenCode sunucusunu başlatmasını engeller.

### `OPENCODESILVER_OPENCODE_HOSTNAME`

OpencodeSilver'ın yönettiği OpenCode sunucusu için bind hostname'i. Varsayılan `127.0.0.1`.

### `OPENCODE_BINARY`

OpencodeSilver'ın çalıştırması gereken `opencode` yürütülebilir dosyasının yolu.

### `OPENCODE_CONFIG`

Belirli bir OpenCode yapılandırma dosyasının yolu.

### `OPENCODE_CONFIG_DIR`

Agent'lar, skills, snippets ve config keşfi için belirli bir OpenCode yapılandırma dizininin yolu.

### `OPENCODE_DATA_DIR`

Yönetilen OpenCode sunucusu için özel veri dizini.

### `OPENCODE_WSL_DISTRO`

Windows'ta OpenCode entegrasyonu için kullanılan WSL dağıtımını seçer.

### `OPENCODESILVER_OPENCODE_WSL_DISTRO`

WSL dağıtımını seçmek için OpencodeSilver'a özel takma ad. İkisi de ayarlıysa `OPENCODE_WSL_DISTRO` önceliklidir.

### `OPENCODE_JWT_SECRET`

UI kimlik doğrulama token'larını imzalamak için kullanılan gizli değer. Kalıcı servis dağıtımlarında uzun ve rastgele bir değer kullanın.

## Terminal ve Git

### `OPENCODESILVER_TERMINAL_SHELL`

OpencodeSilver terminal oturumları için kullanılan shell yürütülebilir dosyası.

### `OPENCODESILVER_GIT_BINARY`

OpencodeSilver Git özelliklerinin kullandığı Git yürütülebilir dosyası.

### `GIT_BINARY`

Alternatif Git yürütülebilir dosyası geçersiz kılma değeri. OpencodeSilver'a özel yapılandırma için `OPENCODESILVER_GIT_BINARY` tercih edin.

### `OPENCODESILVER_GIT_READ_CACHE_TTL_MS`

Git destekli dosya okumaları için önbelleğin milisaniye cinsinden yaşam süresi. Hata ayıklarken bu önbelleği kapatmak için `0` verin.

## Voice ve tunnels

### `OPENAI_API_KEY`

OpencodeSilver ses özelliklerinin doğrudan OpenAI'yi çağırırken kullandığı API anahtarı. Özel bir OpenAI uyumlu sunucuya asla gönderilmez: o sunucuya Ayarlar'da kendi anahtarını verin.

### `OPENCODESILVER_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

`true` ya da `1` olarak ayarlandığında voice özellikleri için uzak OpenAI uyumlu base URL'lere izin verir.

### `NGROK_AUTHTOKEN`

OpencodeSilver tunnel komutlarının kullandığı ngrok auth token. `ngrok config add-authtoken <token>` ile de yapılandırabilirsiniz.

## Runtime yardımcıları

### `BUN_BINARY`

Daemon süreçleri başlatılırken OpencodeSilver'ın kullanması gereken Bun yürütülebilir dosyası.

### `BUN_INSTALL`

Bun kurulum kökü. OpencodeSilver bunu daemon başlangıcı ve güncellemeleri için `bin/bun` bulmakta kullanır.

### `VITE_OPENCODE_URL`

Vite ile derlenen web uygulaması için derleme zamanı API base URL'i. Çoğu kullanıcı bunu normal CLI ya da masaüstü kullanımında ayarlamamalıdır.
