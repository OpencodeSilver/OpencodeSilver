# Variáveis de ambiente

O OpencodeSilver lê estas variáveis na inicialização. Para serviços de inicialização, `opencodesilver startup enable` salva por padrão um snapshot do ambiente atual, então execute de novo após mudar variáveis que o serviço deve usar.

## Servidor OpencodeSilver

### `OPENCODESILVER_HOST`

Endereço onde o servidor web do OpencodeSilver escuta. Use `0.0.0.0` para permitir acesso de outras máquinas.

### `OPENCODESILVER_UI_PASSWORD`

Senha da interface no navegador. Use quando expor fora do localhost, por túnel ou por proxy reverso.

### `OPENCODESILVER_API_ONLY`

Inicia o OpencodeSilver em modo headless quando definido como `true` ou `1`. As rotas de API continuam disponíveis para clientes desktop e mobile, mas a UI do navegador não é servida.

### `OPENCODESILVER_FRAME_ANCESTORS`

Origens que podem mostrar o OpencodeSilver dentro de um frame na própria página, separadas por espaços, por exemplo `https://dash.example.com`. `*` permite qualquer site. Por padrão só o próprio OpencodeSilver e seus apps desktop e mobile podem incorporá-lo, o que impede outros sites de sobrepor os botões dele.

### `OPENCODESILVER_DATA_DIR`

Altera o diretório de dados do OpencodeSilver. O padrão é `~/.config/opencodesilver`.

### `OPENCODESILVER_CHATS_DIR`

Move os diretórios de chat gerenciados que o OpencodeSilver cria para chats sem projeto. O padrão é `~/.config/opencodesilver/chats`. Defina um diretório que o servidor OpenCode consiga ler quando o OpencodeSilver e o OpenCode rodam com usuários diferentes. Os chats existentes não são movidos.

### `OPENCODESILVER_COMPRESS_API`

Controla a compressão das respostas da API. `true` ou `1` ativa; `false` ou `0` desativa.

### `OPENCODESILVER_SKIP_API_COMPRESSION`

Desativa a compressão das respostas da API quando definido como `true` ou `1`. Tem prioridade sobre `OPENCODESILVER_COMPRESS_API`.

### `OPENCODESILVER_VERBOSE_REQUEST_LOGS`

Ativa logs HTTP detalhados quando definido como `true` ou `1`.

### `OPENCODESILVER_UPDATE_API_URL`

Altera o endpoint de verificação de atualizações. A maioria dos usuários deve deixar isso sem definir.

### `OPENCODESILVER_PACKAGE_MANAGER`

Força o gerenciador de pacotes usado em atualizações quando a detecção automática estiver errada.

## Servidor OpenCode

### `OPENCODE_HOST`

Conecta o OpencodeSilver a um servidor OpenCode existente. O valor deve ser um origin `http` ou `https` com porta explícita e sem path, query ou hash. `OPENCODE_HOST` tem prioridade sobre `OPENCODE_PORT`.

### `OPENCODE_PORT`

Define a porta do servidor OpenCode. Com OpenCode gerenciado, solicita essa porta; com `OPENCODE_SKIP_START=true`, conecta a um servidor externo nessa porta.

### `OPENCODE_SKIP_START`

Impede o OpencodeSilver de iniciar seu próprio servidor OpenCode quando definido como `true`.

### `OPENCODESILVER_OPENCODE_HOSTNAME`

Hostname do servidor OpenCode gerenciado pelo OpencodeSilver. O padrão é `127.0.0.1`.

### `OPENCODE_BINARY`

Caminho para o executável `opencode` que o OpencodeSilver deve usar.

### `OPENCODE_CONFIG`

Caminho para um arquivo de configuração específico do OpenCode.

### `OPENCODE_CONFIG_DIR`

Caminho para o diretório de configuração do OpenCode para agents, skills, snippets e descoberta de config.

### `OPENCODE_DATA_DIR`

Diretório de dados personalizado para o servidor OpenCode gerenciado.

### `OPENCODE_WSL_DISTRO`

Escolhe a distro WSL usada pela integração do OpenCode no Windows.

### `OPENCODESILVER_OPENCODE_WSL_DISTRO`

Alias específico do OpencodeSilver para escolher a distro WSL. `OPENCODE_WSL_DISTRO` tem prioridade quando ambas estão definidas.

### `OPENCODE_JWT_SECRET`

Segredo usado para assinar tokens de autenticação da UI. Em serviços persistentes, use um valor longo e aleatório.

## Terminal e Git

### `OPENCODESILVER_TERMINAL_SHELL`

Executável de shell usado nas sessões de terminal do OpencodeSilver.

### `OPENCODESILVER_GIT_BINARY`

Executável do Git usado pelos recursos Git do OpencodeSilver.

### `GIT_BINARY`

Override alternativo para o executável do Git. Para configuração específica do OpencodeSilver, prefira `OPENCODESILVER_GIT_BINARY`.

### `OPENCODESILVER_GIT_READ_CACHE_TTL_MS`

TTL, em milissegundos, para leituras de arquivos em cache baseadas em Git. Use `0` para desativar o cache durante depuração.

## Voz e túneis

### `OPENAI_API_KEY`

API key usada pelos recursos de voz do OpencodeSilver quando chamam a própria OpenAI. Ela nunca é enviada a um servidor próprio compatível com OpenAI: dê a esse servidor uma chave própria nas Configurações.

### `OPENCODESILVER_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Permite base URLs remotas compatíveis com OpenAI para recursos de voz quando definido como `true` ou `1`.

### `NGROK_AUTHTOKEN`

Token de autenticação do ngrok usado pelos comandos de túnel do OpencodeSilver. Você também pode configurar com `ngrok config add-authtoken <token>`.

## Auxiliares de runtime

### `BUN_BINARY`

Executável do Bun que o OpencodeSilver deve usar ao iniciar processos daemon.

### `BUN_INSTALL`

Raiz da instalação do Bun. O OpencodeSilver usa isso para encontrar `bin/bun` ao iniciar daemons e atualizar.

### `VITE_OPENCODE_URL`

API base URL de build-time para a web app criada com Vite. A maioria dos usuários não deve usar isso no CLI ou desktop normal.
