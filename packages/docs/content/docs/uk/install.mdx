# Встановлення

Є три способи запустити OpencodeSilver:

- десктоп-застосунок для macOS
- вебзастосунок на базі CLI, який можна встановити як застосунок на телефоні (PWA)
- розширення для VS Code

## Передумова

Спершу встановіть [OpenCode](https://opencode.ai) — OpencodeSilver працює поверх нього.

## Веб + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/opencodesilver/opencodesilver/main/scripts/install.sh | bash
opencodesilver --ui-password be-creative-here
```

Відкрийте URL, який вивів CLI (зазвичай `http://localhost:3000`). Ви маєте побачити список сесій OpencodeSilver. Щоб він був під рукою, скористайтеся опцією «Install» в адресному рядку браузера й додайте його як застосунок.

## Десктоп

Завантажте найновішу десктопну збірку зі сторінки релізів на GitHub або зі сторінки завантаження OpencodeSilver. Відкрийте її та увійдіть у свій звичний робочий процес OpenCode.

## VS Code

Встановіть із VS Code Marketplace і увійдіть у свій звичний робочий процес OpenCode. Після цього вікно OpencodeSilver відкриється на бічній панелі.
