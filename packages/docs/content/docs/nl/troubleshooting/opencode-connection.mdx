# Verbinding met OpenCode

Als OpencodeSilver wel laadt maar blijft melden dat OpenCode opnieuw wordt gestart, of als de chat niet reageert, is de achterliggende server niet bereikbaar. Loop de volgende controles na.

## De melding over opnieuw starten blijft staan

- wacht direct na het openen even; tijdens het starten van de server is deze melding normaal
- controleer met `opencodesilver status` of de server draait
- herstart met `opencodesilver restart`
- bekijk de opstartdetails met `opencodesilver logs`

## U gebruikt een eigen server

Als OpencodeSilver met een bestaande server moet verbinden, controleer dan de instellingen uit [OpenCode-server](/nl/opencode-server/):

- `OPENCODE_HOST` moet de poort bevatten en mag geen pad hebben, bijvoorbeeld `http://localhost:4096`
- stel `OPENCODE_SKIP_START=true` in, zodat OpencodeSilver niet ook zelf een server start
- bij een ongeldig adres negeert OpencodeSilver het en start het zelf een server; zoek in de logs naar een waarschuwing met `[config]`

## Het werkt nog steeds niet

- controleer of Node.js versie `20` of nieuwer is geïnstalleerd
- installeer de nieuwste CLI opnieuw
- open eerst rechtstreeks `http://localhost:3000` voordat u een tunnel- of remotelink probeert
