# OpencodeSilver v2.4.0 Release Notes

**Release Date:** October 6, 2026  
**Status:** Stable  

---

## 📌 Overview
Major functional expansion introducing safety guards for CLI execution, real-time context token metrics, full desktop Windows installer generation, and official VS Code extension packaging.

---

## 🚀 Key Features & Innovations
1. **🛡️ Command Safety Inspection & Dry-Run**:
   - Real-time command analysis detecting destructive commands (`rm -rf`, `git reset --hard`, `mkfs`, format commands).
   - High-contrast visual caution banner before executing potentially hazardous terminal commands.
2. **📊 Live Context Token Usage Indicator**:
   - Dynamic token estimator in the status bar calculating conversation token depth against typical model context windows (200k / 1M).
   - Color-coded indicators (Normal, Warning, Critical) to prevent context truncation during long sessions.
3. **💻 Windows Desktop Installer (`.exe`)**:
   - Complete compilation and bundling of `OpencodeSilver-2.4.0-win-x64.exe` with bundled internal backend.
4. **🔌 VS Code Extension (`.vsix`)**:
   - Official release of `opencodesilver-2.4.0.vsix` for VS Code integration.
5. **✨ Comprehensive Documentation**:
   - Overhauled README with technical architecture diagrams, setup guidelines, and preview galleries.
