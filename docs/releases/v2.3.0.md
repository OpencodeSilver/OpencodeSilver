# OpencodeSilver v2.3.0 Release Notes

**Release Date:** October 6, 2026  
**Status:** Stable  

---

## 📌 Overview
Major UI overhaul introducing direct feedback loops, dedicated update checks, GitHub issue/discussion launchers, and sprite icon integration.

---

## 🚀 Key Features & Improvements
- **Direct GitHub Feedback Actions**: Added dedicated buttons in the desktop sidebar and About dialog for checking updates, reporting bugs, and proposing ideas.
- **Project Sprite System**: Standardized SVG sprite icons (`sprite.svg`) across sidebar and modals for update (`sparkling`), issues (`alert`), and discussions (`message-square`).
- **Interactive Toast Notifications**: Integrated toast feedbacks displaying version checks and action confirmations directly inside the UI.
- **Mobile Connect Key Cleanup**: Fixed persistent mobile connection logs to clear under the actual written storage key.
- **Branding Realignment**: Golden/silver visual identity overhaul across dialogs, landing screens, and typography.
