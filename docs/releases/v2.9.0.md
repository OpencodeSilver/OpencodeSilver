# OpencodeSilver v2.9.0 Release Notes

**Release Date:** October 8, 2026  
**Status:** Latest Stable Release  

---

## 📌 Overview
OpencodeSilver v2.9.0 delivers the **Background Agent Trajectory & Plan Detection Engine** across the Desktop application and VS Code extension, complete **14-Language Localization (45 new keys × 14 languages = 630 translations)**, defensive message record guards eliminating `TypeError: Cannot read properties of undefined (reading 'role')`, and a streamlined composer toolbar with the legacy Quick Prompt template selector removed.

---

## 🚀 Key Features & Improvements in v2.9.0

### 1. ⚡ Background Agent Trajectory & Plan Detection Engine (محرك التتبع واكتشاف المخططات بالخلفية)
- **Files:**
  - `packages/ui/src/components/chat/StatusRowContainer.tsx`
  - `packages/ui/src/components/chat/StatusRow.tsx`
  - `packages/ui/src/components/chat/AntigravityLiveTrajectoryDrawer.tsx`
  - `packages/ui/src/components/chat/AntigravityArtifactActionRow.tsx`
- **Functionality:**
  - Real-time extraction of agent `toolAction` (progressive verb phrase) and `toolSummary` (noun phrase) from active tool invocations (`read`, `view_file`, `edit`, `replace_file_content`, `write`, `write_to_file`, `bash`, `shell`, `run_command`, `grep`, `glob`, `webfetch`, `websearch`, `task`, `skill`).
  - Automatic background detection of executable implementation plans and architectural blueprints, automatically synchronizing plan availability with `useSessionUIStore` without cluttering the area above the bottom chat input box.
  - Background token estimation and trajectory tracking operate silently in a hidden DOM layer while keeping the chat input area completely clean when idle.

### 2. 🛡️ Defensive Session Message Record Normalization (إصلاح خطأ قراءة `role` في رسائل الجلسة)
- **Files:**
  - `packages/ui/src/components/chat/StatusRowContainer.tsx`
  - `packages/ui/src/components/chat/AntigravityLiveTrajectoryDrawer.tsx`
  - `packages/ui/src/components/chat/AntigravityArtifactActionRow.tsx`
- **Functionality:**
  - Migrated `StatusRowContainer` to `useSessionMessageRecords` and added defensive `getRole(rec)` (`rec?.info?.role ?? rec?.role`) and `Array.isArray(rec?.parts)` checks across all trajectory and artifact inspectors, completely preventing `TypeError: Cannot read properties of undefined (reading 'role')`.

### 3. 🧹 Streamlined Composer Toolbar (إزالة خيار إدراج نموذج جاهز)
- **Files:**
  - `packages/ui/src/components/chat/composer/ui/ComposerToolsControls.tsx`
  - `packages/ui/src/components/chat/QuickPromptDropdown.tsx`
  - `packages/ui/src/lib/prompts/quickPromptTemplates.ts`
- **Functionality:**
  - Removed the legacy Quick Prompt Templates (`إدراج نموذج أمر جاهز وسريع`) dropdown from the composer toolbar across both the Desktop application and VS Code extension, keeping the toolbar focused on AI Prompt Optimization, Session Metrics, Markdown Export, and One-Click Cache Purge.

### 4. 🌍 Full 14-Language Localization (`45 Keys × 14 Languages = 630 Translations`)
- **Files:** `packages/ui/src/lib/i18n/messages/{en,ar,de,es,fr,ja,ko,nl,pl,pt-BR,tr,uk,zh-CN,zh-TW}.ts`
- **Functionality:**
  - Added native translations for all new trajectory, plan detection, and tool status keys across all 14 supported languages, plus localized `command.optimizePrompt.title` in `packages/vscode/package.nls.{ar,fr,tr}.json`.

### 5. 🎨 Unified Monochrome Icon System (توحيد الأيقونات باللونين الأبيض والأسود بتصميم المشروع)
- **Files:**
  - `scripts/generate-icon-sprite.mjs`
  - `packages/ui/src/components/icon/sprite.ts`
  - `packages/ui/src/components/session/sidebar/shell/SidebarFooter.tsx`
  - `packages/ui/src/components/ui/AboutDialog.tsx`
  - `packages/ui/src/components/sections/opencodesilver/AboutSettings.tsx`
  - `packages/ui/src/lib/settings/metadata.ts`
- **Functionality:**
  - Redesigned the **OpencodeSilver** (`opencodesilver`), **Reports** (`report-issue`), **Request Ideas** (`idea-spark`), and **Update** (`update-sync`) icons in clean geometric monochrome line art (`currentColor`) matching the project's black & white design language across sidebar footer, About dialog, and Settings.
