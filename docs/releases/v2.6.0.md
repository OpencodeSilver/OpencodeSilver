# OpencodeSilver v2.6.0 Release Notes

**Release Date:** October 7, 2026  
**Status:** Latest Stable Release  

---

## 📌 Overview
Major feature and platform expansion release:
1. **Full Integration of Chat Tools & AI Prompt Optimizer** right inside the composer toolbar.
2. **VS Code Extension Integration & Command Expansion**: Added contextual prompt optimization (`opencodesilver.optimizePrompt`) directly in the editor context menu and command palette.
3. **Full 14-Locale i18n Internationalization** across all tools, prompts, metric dashboards, and optimization actions.

---

## 🚀 Key Features in v2.6.0

### 1. 🪄 AI Prompt Optimizer (تحسين النص بالذكاء الاصطناعي)
- **Files:** `packages/ui/src/lib/prompts/promptOptimizer.ts`, `packages/ui/src/components/chat/composer/ui/ComposerToolsControls.tsx`
- **Functionality:** 
  - Analyzes the input context (new project creation, bug diagnosis, refactoring, unit tests, performance tuning) and turns simple thoughts into an authoritative, structured prompt specification.
  - Automatically adheres to the language of the prompt (Arabic, English, French, etc.).
  - Replaces or enriches the draft in the chat composer instantly with 1 click.

### 2. 🧩 Composer Internal Toolbar Integration
- **Files:** `packages/ui/src/components/chat/composer/ui/ComposerToolsControls.tsx`, `ComposerFooter.tsx`, `ChatInput.tsx`
- **Functionality:**
  - Removed clutter from the top floating status row and harmoniously placed all 4 primary tools into the chat input bar.
  - **Quick Prompts (`book-open`):** Instant pre-made templates for fixing bugs, explaining code, unit testing, refactoring, performance optimization, and git commit drafting.
  - **Session Metrics (`bar-chart`):** Interactive modal providing real-time stats on turns, tools run, character/token usage, and files altered.
  - **Session Exporter (`download`):** Instant export of conversation threads and tool runs to clean Markdown files.
  - **Cache Purge (`delete-bin`):** One-click cleanup of transient caches with real-time counters and status feedback.

### 3. 💻 VS Code Extension Deep Integration
- **Files:** `packages/vscode/package.json`, `packages/vscode/package.nls.json`, `packages/vscode/src/extension.ts`
- **Functionality:**
  - New command `opencodesilver.optimizePrompt` ("Optimize Prompt with AI") accessible from:
    - Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
    - Right-click Context Menu (`OpencodeSilver` -> `Optimize Prompt with AI`)
  - Automatically incorporates active editor selection or prompts user with an interactive input box to build an optimized task prompt.

### 4. 🌍 Comprehensive 14-Language Localization
- **Locales:** `ar`, `en`, `de`, `fr`, `es`, `nl`, `ja`, `ko`, `pl`, `pt-BR`, `tr`, `uk`, `zh-CN`, `zh-TW`
- 100% key parity across all language dictionaries with verified automated test assertions.
