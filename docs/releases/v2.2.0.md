# OpencodeSilver v2.2.0 Release Notes

**Release Date:** October 2026  
**Status:** Stable  

---

## 📌 Overview
Enhancements to CI/CD pipelines, single-publisher release orchestration, and auto-updater asset delivery.

---

## 🚀 Key Features & Fixes
- **Unified Release Publisher**: Single-publisher workflow in GitHub Actions to prevent race conditions during artifact generation.
- **Auto-Updater Delta Blockmaps**: Generation and deployment of Windows `.exe.blockmap` assets enabling faster, differential updates.
- **Electron Updater Feeds**: Updated electron-updater repository endpoints directly targeting `OpencodeSilver/OpencodeSilver`.
- **Packaging Reliability**: Cleaned native dependencies and streamlined build scripts for Windows x64.
