# OpencodeSilver v2.8.0 Release Notes

**Release Date:** October 7, 2026  
**Status:** Stable Release  

---

## 📌 Overview
OpencodeSilver v2.8.0 introduces the redesigned **Skills Marketplace & Catalog** with GitHub author avatars, real-time filtering, and direct Context Rail integration, alongside the **Production-Hardened External Tunnel** engine featuring automated pre-flight diagnostics, `cloudflared` / `ngrok` fallback, and 14-language localization.

---

## 🚀 Key Features in v2.8.0

### 1. 🛒 Redesigned Skills Marketplace & Catalog (سوق وكتالوج المهارات)
- **Files:** `packages/ui/src/components/views/MarketplaceView.tsx`, `packages/ui/src/components/sections/skills/catalog/SkillsCatalogSection.tsx`
- **Functionality:**
  - Complete visual and functional overhaul of the Skills & Extensions Hub into a high-contrast monochrome marketplace.
  - Dynamic GitHub author profile avatars fetched directly from source repositories (`OpenAI`, `Anthropic`, `Cursor`, `Matt Pocock`, `OpencodeSilver`, etc.).
  - Real-time search across curated skill repositories, instant one-click custom Git repository source additions, and verified package badges.

### 2. 🧭 Context Rail & Surface Integration (شريط السياق الجانبي)
- **Files:** `packages/ui/src/components/layout/ContextRail.tsx`, `packages/ui/src/components/layout/ContextPanel.tsx`
- **Functionality:**
  - Added instant navigation to the Skills Marketplace right from the primary vertical Context Rail with a dedicated sparkling star icon.
  - Switch seamlessly between Chat, Files, Git, and Skills without losing workspace context.

### 3. 🌐 Production-Hardened External Tunnel (النفق الخارجي وتوجيه الاتصالات)
- **Files:** `packages/ui/src/components/sections/openchamber/TunnelReadinessModal.tsx`, `packages/electron/main.mjs`
- **Functionality:**
  - Automated pre-flight diagnostics for remote instance exposure.
  - Intelligent fallback across tunneling providers (`cloudflared` and `ngrok`), one-click copyable installation commands (such as `winget install --id Cloudflare.cloudflared` on Windows), and credential verification.

### 4. 🌍 14-Language Localization for Marketplace & Tunnel
- **Files:** `packages/ui/src/lib/i18n/messages/*.settings.ts`
- **Functionality:**
  - Full localization across all 14 supported languages (`en`, `ar`, `de`, `es`, `fr`, `ja`, `ko`, `nl`, `pl`, `pt-BR`, `tr`, `uk`, `zh-CN`, `zh-TW`) for all marketplace and tunnel diagnostic surfaces.
