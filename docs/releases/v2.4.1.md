# OpencodeSilver v2.4.1 Release Notes

**Release Date:** October 7, 2026  
**Status:** Stable  

---

## 📌 Overview
Maintenance and engine upgrade release incorporating the upstream OpenCode CLI version 2.0.24 backend, resolving execution incompatibilities and updating cross-platform download feeds.

---

## 🚀 Key Features & Updates
- **⚡️ OpenCode CLI 2.0.24 Core Engine**:
  - Upgraded internal runtime and binary resolution to OpenCode CLI `2.0.24`.
  - Fixed terminal upgrade warning prompt ("OpenCode CLI upgrade failed. Run opencode upgrade in a terminal for details").
- **💻 Desktop Installer v2.4.1**:
  - Rebuilt `OpencodeSilver-2.4.1-win-x64.exe` with bundled OpenCode 2.0.24 engine.
- **🔌 VS Code Extension v2.4.1**:
  - Updated `opencodesilver-2.4.1.vsix` with improved server connection retry logic.
- **🌐 English Documentation Overhaul**:
  - Translated complete project documentation to international English standards.
  - Corrected asset URLs pointing to v2.4.1 direct releases.
