# OpencodeSilver v2.5.0 Release Notes

**Release Date:** October 7, 2026  
**Status:** Latest Stable Release  

---

## 📌 Overview
Milestone release delivering **10 brand new core features** across user experience, session management, development workflows, and safety verification. Tested with 100% test pass rate across unit and type suites.

---

## 🚀 The 10 New Core Features

### 1. 📤 Smart Session Exporter
- **Files:** `packages/ui/src/lib/session/sessionExporter.ts`, `SessionExporterButton.tsx`
- **Functionality:** 1-click export of current conversation thread, code snippets, and execution logs into cleanly structured Markdown (`.md`) or raw JSON (`.json`) files.

### 2. 📋 Enhanced Codeblocks with Fast Copy & Line Badges
- **Files:** `packages/ui/src/components/chat/message/parts/VirtualizedCodeBlock.tsx`
- **Functionality:** Dedicated header bar above code blocks displaying code language badge, total line count, and a 1-click clipboard copy button with instantaneous toast confirmation.

### 3. 🎯 Quick Prompt Templates Dropdown
- **Files:** `packages/ui/src/lib/prompts/quickPromptTemplates.ts`, `QuickPromptDropdown.tsx`
- **Functionality:** Fast input helper offering one-click prompt presets (Fix Bugs, Write Tests, Code Review, Optimize Performance, Generate Commit Message).

### 4. 🛡️ Secret Leak Protection Scanner
- **Files:** `packages/ui/src/lib/safety/secretScanner.ts`, `UserTextPart.tsx`
- **Functionality:** Real-time client-side regex scanner inspecting prompt inputs for accidentally pasted credentials (OpenAI, GitHub, Anthropic, AWS keys) with visual warning badges.

### 5. 📊 Session Metrics & Summary Dashboard Card
- **Files:** `packages/ui/src/lib/session/sessionMetricsCalculator.ts`, `SessionMetricsCard.tsx`
- **Functionality:** Real-time metrics breakdown displaying total user turns, assistant responses, tools invoked, estimated token count, and modified files.

### 6. 🧹 One-Click Cache Purge & Transient State Cleaner
- **Files:** `packages/ui/src/lib/maintenance/cacheCleaner.ts`, `CacheCleanerButton.tsx`
- **Functionality:** Maintenance utility to flush volatile storage, local indexed states, and stale cache entries without logging the user out.

### 7. ⭐ Starred / Bookmarked Assistant Responses
- **Files:** `packages/ui/src/lib/bookmarks/starredMessages.ts`, `StarMessageButton.tsx`
- **Functionality:** Allows bookmarking critical answers, architectural explanations, or command recipes for fast retrieval.

### 8. 🔊 Audible Task Completion Chime
- **Files:** `packages/ui/src/lib/sound/taskChime.ts`, `StatusRowContainer.tsx`
- **Functionality:** Synthesizes a pleasant audio chime using the Web Audio API whenever an asynchronous terminal command or background task finishes while the window is inactive.

### 9. 🔀 Enhanced Unified & Split Diff View Toggles
- **Files:** `packages/ui/src/components/chat/message/DiffViewToggle.tsx`
- **Functionality:** Visual toggle controls allowing developers to switch effortlessly between Side-by-Side (Split) and Unified inline diff representations.

### 10. ⏱️ Turn Latency Tracker
- **Files:** `packages/ui/src/lib/performance/turnLatencyTracker.ts`
- **Functionality:** Precision microsecond latency stopwatch calculating round-trip inference speed and tool execution durations.
